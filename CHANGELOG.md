# Changelog

## 1.1.0 native Android conversion

- Added a complete React Native Community CLI Android project.
- Replaced file-based routing with React Navigation while preserving route behavior.
- Replaced platform services with Android-native libraries for gradients, blur, encrypted storage, device authentication, native notification channels, splash handling, and haptics.
- Preserved the existing screen components, assets, motion, data layer, user flows, and visual design.
- Added Android Studio, Gradle, Hermes, New Architecture, release shrinking, environment generation, validation, and production handoff documentation.
